# Summary

Enzymes are characterized by how fast they work at different substrate concentrations, and inhibitors by how strongly they slow an enzyme down. These properties are summarized by a few parameters (the maximum rate Vmax, the Michaelis constant Km [@Johnson2011], the half-maximal inhibitory concentration IC50 and the inhibition constant Ki) that are estimated by fitting curves to measured rates. Enzymatic Kinetics Analyzer is a Python package that performs these fits, reports each parameter with a confidence interval, keeps replicate measurements as separate data points, compares competing inhibition mechanisms, and processes many enzymes, conditions or compounds in one call.

# Statement of need

Kinetic data sets are small, typically six to twelve concentrations, and small data sets make uncertainty easy to misstate. Intervals computed from the normal distribution are too narrow at these sample sizes, averaging replicates before fitting discards information and degrees of freedom, and an IC50 interval that is symmetric on a linear scale can include negative concentrations. These problems are common in spreadsheets and one-off scripts. The package is intended for biochemists and students who analyze kinetic and dose-response data in Python and want results whose uncertainties are computed correctly and whose limitations are stated, together with a test suite that checks those properties.

# State of the field

Commercial curve-fitting packages are widely used in biochemistry but are not scriptable in open pipelines. In R, the drc package [@Ritz2015] provides a comprehensive framework for dose-response models and renz [@Aledo2022] covers enzyme kinetic analysis, including linearized and nonlinear Michaelis-Menten fitting. In Python, SciPy [@Virtanen2020] supplies the nonlinear least-squares engine but no kinetic models, interval conventions or laboratory data readers.

Enzymatic Kinetics Analyzer was built as a Python package rather than as a contribution to these R packages so that kinetic analysis can sit in the same environment as the Python tools increasingly used for laboratory automation, instrument data processing and machine learning. It deliberately covers a narrow set of models with careful defaults instead of the breadth of drc.

# Software design

The package separates models (`models`), fitting (`fitting`), input conversion (`io`), batch processing (`batch`) and output (`plotting`, `report`). Every fit returns a `FitResult` with parameters, standard errors from the scaled covariance matrix, Student's t confidence intervals with n - p degrees of freedom, the residual sum of squares, R-squared and the small-sample Akaike information criterion (AICc) [@Hurvich1989].

Three design choices address the problems above. Replicates are fitted as individual points, and the readers convert common spreadsheet layouts to a long format that makes this the default. The four-parameter logistic model is fitted on log10(IC50), so the IC50 interval is symmetric on the logarithmic scale and never includes zero; the plateaus can be fixed, for example at 0 and 100 for percent activity. Competitive, uncompetitive and mixed inhibition are fitted globally to all substrate and inhibitor concentrations and ranked by AICc with Akaike weights, so that the evidence for a mechanism is reported rather than assumed. Batch dose-response fits add plain-language warnings when an IC50 lies outside the tested range, when fewer than two concentrations lie on one side of it, or when a plateau is extrapolated beyond the data.

The intervals are asymptotic and can still be too narrow when an experiment does not constrain a parameter, for example Km when no substrate concentration exceeds it; the documentation states this. Integrated rate equations and progress-curve fitting are outside the current scope.

The test suite checks exact parameter recovery from noise-free data, the t-based interval construction, the coverage of Km intervals in repeated simulated experiments (\autoref{fig:coverage}), the use of replicates in the fit, the log-scale symmetry of IC50 intervals, fixed plateaus, identification of the simulated inhibition mechanism, the data readers, and that all examples run. Continuous integration runs the tests on Linux, macOS and Windows.

# Research impact statement

The package gives laboratories and courses a tested, open Python route from raw rates to kinetic parameters with correctly sized uncertainties, and makes the choice between inhibition mechanisms explicit. \autoref{fig:coverage}b shows why this matters at typical sample sizes: with six to eight substrate concentrations, normal-distribution intervals covered the true Km in fewer than 90% of simulated experiments, against a nominal 95%.
